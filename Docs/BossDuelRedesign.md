# Boss 攻防博弈改造

本轮将现有招式库改为按玩家行为选择与分支，沿用模型、招式碰撞、网络快照和技能编号。
设计取向：借鉴《黑神话：悟空》的观察、诱招与收招反击，以及《影之刃零》的连续攻防和防守方式切换；不是复刻两款游戏的数值或动作资产。

## 玩家可以主动影响什么

| 玩家行为 | Boss 回应 | 玩家反制 |
| --- | --- | --- |
| 持续举防至少 0.45 秒 | 提高不可格挡攻击权重；二阶段可切换破防后续 | 看新的颜色与范围，侧移、撤退或进入安全内圈 |
| 短时间连续闪避 | 提高前摇较长的招式权重 | 不连按翻滚，等待真正出手；习惯记忆会随时间消退 |
| 持续轻击 | 有反架势招式的 Boss 更倾向于架势反击 | 停手骗空、重击破架势或绕背 |
| 明确开始喝药或蓄力 | 观察至少 0.18 秒后，考虑突刺、追身或狙击 | 先拉开距离、诱出攻击，再利用完整收招窗口 |
| 成功弹反 | 阻止该招后的追加追击和中途分支 | 爱音仍保留当前招式的剩余拼刀拍数，但不会接新一套 |
| 保持中立，按时防守而非连续闪避 | 没有可利用的行为时不自动随机续招 | 等最后一击后的收招反击 |

## 变招规则

- 一阶段学习原招式；二、三阶段允许第一拍之后改变后续。
- 只在 2–4 拍招式的第一击后至少 0.18 秒、第二击锁向之前分支；长终结技不分支。
- 新招从零计时，完整播放预警，前摇不低于 0.45 秒。不在已经锁定的攻击上临时改变属性。
- 一次中途分支消耗全部续招预算，分支结束后进入收招与迂回。
- 场上仍有危险物、Boss 正在脱困保护、双 Boss 同伴存活或本招已被弹反时，不进行中途分支。
- 普通招式结束后的续招仍保留完整收招，只从符合已观察行为的招式中选择；达到原有阶段上限后必定停手。
- 爱音既有剑庭接近战属于场景招式的例外，仍保留，但弹反可阻止其追加。

## 各 Boss 的对决重点

| Boss | 使用现有招式产生的分支特色 |
| --- | --- |
| 大肥鱼 | 举防引出涡流，近身连续闪避引出回身尾，远处喝药引出点名；不恢复已经退役的追踪跳砸 |
| 菲比 / 糯糯 | 行为权重影响各自拳掌选招；双人存活时不增加中途抢招，保留轮流施压 |
| 爱音 | 拼刀可压制续招；轻击可诱架剑，再选择重击破守；举防引出突刺或下段 |
| 塔菲 | 用射击、狙击及布设区分远近应对，保留换弹窗口 |
| 香企鹅 | 举防引出裂地与空间攻击，连续闪避增加慢前摇选择；保留重锤风格 |
| 娅娅 | 按距离与行为在鞭刺、内外圈和丝阵之间选择，玩家需判断进或退 |
| 残躯 | 保留击杀成长和招式库，反应改为读取已发生的动作，使用相同变招上限 |

## 实现与验证

- `TrialDuelRead`：单个目标的动作观察、反应延迟和衰减记忆；换目标或重试清空。
- `TrialChampionDuel`：基于当前实际招式库与攻击距离选择后续，控制分支预算。
- `TrialChampion` / `TrialChampionTactics` / `TrialBoss`：接入选择、弹反和重置。
- 网络仍由主机决定技能，客户端使用已有技能编号、进度与危险物快照呈现，不在客户端重复作决策。
- Editor 菜单 `Tools/Tomorin/Validate duel decisions` 验证观察延迟、取消动作、习惯衰减、目标切换及各 Boss 的候选招式。
- `TrialDuelValidation.ValidateLive` 验证初始化后的爱音分支、完整前摇、预算和弹反停追。

本轮没有新增动作资源。视觉辨识度、整场难度和双客户端网络延迟体验仍需要实机试玩调节。
