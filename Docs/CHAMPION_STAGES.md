# 五场 Boss 挑战

2026-11-03，Unity 6000.3.27f2 / URP 17.3.0。

从 InkStart 的单人或联机选关进入。五个场景使用原有 TrialGame、玩家、HUD 和房主权威战斗；场景在启动时构建约 48×48 米的场地，并按材质和空间分区合并静态网格。

| 关卡 | Scene | 生命（单人） | 核心 |
| --- | --- | --- | --- |
| 菲比与糯糯 | TwinLotusCourt | 1800 + 1800 | 双人近战、换位、擒拿、交替追压 |
| 爱音 | CrimsonSwordTerrace | 3200 | 连续拼刀、架势、反架势、剑气、飞刃 |
| 塔菲 | NeonBallisticsHarbor | 3000 | 导入的 M4、实体弹道、跳弹、地雷、炮台 |
| 香企鹅 | GlacialForge | 3600 | 重锤、投锤、裂地、冰柱、引力重锻 |
| 娅娅 | MoonSilkObservatory | 3300 | 长鞭、内外圈、牵引、迟发陷阱、可斩丝线 |

每名角色 16 招。首阶段开放前 12 招；生命低于 65% 开放全部招式，低于 30% 进一步缩短两招之间的间隔。双人关一人倒下后，另一人直接进入决意阶段，必须击败两人才通关。当前可用招式使用不放回选择，整轮用完才重新循环，同时根据距离、玩家架势和已开始的喝药/重击动作调整权重。房主按人数缩放生命并保留剩余比例。

普通剑、拳、鞭连段约 0.28–0.42 秒一拍；每次接触都有独立提示，停止追踪后才判定。范围危招保留更长蓄力。恢复期与架势崩溃不会触发自动闪避；侧闪有独立冷却。飞跃会移动实际角色和受击框，地面攻击不会命中数米高的 Boss。

## 玩家变招

- 格挡中接轻/重击：防守突刺。
- 奔跑接轻/重击：奔跑拔刀。
- 闪避后接重击：腾空重斩。
- Boss 破架势时近身重击：处决斩。
- 地雷、炮台、丝线可用剑清除；火箭和冰柱需要重斩。
- 反击架势会接住轻击，用重击可破守，也可等其落空。
- 子弹按实际来向判断防守，背后的跳弹不能靠面向 Boss 的格挡化解。

## 资产与性能

六个原始 FBX 保留。菲比、糯糯和娅娅原文件具有骨架但没有可用的网格变形权重，生成的战斗副本增加分段蒙皮；爱音、塔菲和香企鹅保留导入权重。动作基于各自骨架制作，由玩法时钟驱动并导出 150 个 Generic 片段及六个预览控制器。爱音移动采用按腿长与真实位移驱动的步频、方向性步态和脚部 IK。

每个 Boss 共用固定 48 槽弹体/陷阱池；投剑和飞锤模型预热两份。常规战斗不反复创建、销毁弹体，目标列表复用，技能 HUD 文案按状态变化更新。新关房主快照 30 Hz，输入仍按原有高频通道发送；只同步活动技能物。

开始界面的背景 UV 不再随鼠标或正弦噪声变化；仅保留独立雾气与粒子。

## 验证

202 项资产/蒙皮/脚步/机制类别检查、514 项 Play Mode 检查通过。覆盖全部 96 招的预警、停止追踪、安全位置、清场，以及弹反、闪避、腾空受击框、反架势、破坏陷阱、双 Boss 胜利与重试。证据：Logs/Trial/ChampionAssetValidation.txt、ChampionRuntimeValidation.txt。

最终整合版本的本机编辑器短时采样：静态五关约 7.4–8.7 ms/帧；塔菲连续弹雨约 6.7 ms/帧，峰值 26 / 48 个活动弹体。该数据包含编辑器开销，仅是当前机器与短时场景的测量，不代表所有硬件、设备、玩家人数或长期激战的帧率保证。

真实 TCP 联机通过 40 项检查：五关选关、双人生命缩放、独特技能与带类型弹体的同步、陷阱清理及断线返回菜单。证据：Logs/Trial/ChampionNetworkValidation.txt。按用户要求未构建或导出 Windows 版本包。

可以通过 Tools > Tomorin > Champions 的资产、五关 Play Mode、真实 TCP 三组菜单重跑。首次生成全套资产请在非 Play Mode 使用 Build five boss stages and all animations。

节奏与机动设计的参考方向：[S-GAME 官方战斗介绍](https://blog.playstation.com/2026/08/17/phantom-blade-zero-state-of-play-dives-deep-into-combat-and-the-wulin-world/)。上述前摇、连段与反制数值均为本项目的实际配置。
