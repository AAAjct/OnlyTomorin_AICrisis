# 连招音效扩充

新增 19 组、76 条原创合成音效（单声道、44.1 kHz、PCM16），战斗音效库共 139 条；新增 WAV 约 2.78 MiB。每组四个变体改变包络、滤波、脉冲节奏及音高。

| 分类 | 声音 |
| --- | --- |
| 刀法 | 轻斩、重斩、突刺、上挑、横扫、拔刀、旋转、空中斩 |
| 体术 | 柄击 / 肘击、腿法 |
| 技能 | 赤刃、月刃、火龙、回旋剑、樱散、砂落、收剑 |
| 命中 | 体术钝击、穿刺命中 |

`TrialEffects.MoveSoundKey` 按实际招式选择音色；基础四连击依次使用轻斩、横扫、突刺、旋转音色。单人起手和客户端状态同步使用相同映射，技能释放继续由原有战斗事件驱动。体术移除了接触视觉事件中重复播放的闪避声。

每个音效组独立洗牌，一组全部播放后才开始下一轮，轮次边界也避免连续重复。选音不再依赖共享音源池索引，并使用独立随机数源。攻击类有小幅音高 / 音量变化，仍受攻击音效音量控制。75 ms 内同类赤刃 / 月刃只播放一次发射声，避免一波多枚剑气同时叠音；碰撞命中声独立保留。

新增短音效使用 PCM、DecompressOnLoad 和预载音频数据。原资源和 GUID 保留。仅重建新增音效：`python Tools/create_combo_audio.py`；重建全部音效：`python Tools/create_combat_audio.py`。

验证命令：`unity command script eval_file --file Tools/validate_combo_audio.cs`（Edit Mode）。覆盖 76 条资源的可读性、信号电平、四变体差异，40 组音效的 4,448 次防重复选音，以及 148 个招式 / 轻重动作组合的资源覆盖。自动检查能确认播放选音和信号数据，最终混音听感仍以实际游玩试听为准。
