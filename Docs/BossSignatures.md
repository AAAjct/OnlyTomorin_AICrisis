# Boss 独立招式与特效（2026-11-05）

2026-11-06 的阶段追击、短硬直缩放及对空弹道更新见 [BossEscalation.md](BossEscalation.md)。本页的短硬直时长为基础值。

玩家基础耐力从 280 调到 420，消耗、恢复速度与增益额外耐力维持原规则。

普通命中的 Boss 产生 0.13 秒短硬直，重击为 0.22 秒；0.38 秒触发间隔防止永久锁住动作。短硬直暂停身体及攻击时钟，不触发处决增伤。已释放的场地攻击独立推进。成功格挡、反击、闪避与破围护身按其防御规则处理；架势崩溃仍保留原来的长处决窗口。

## 爱音

- 开场 3.5 秒：中心剑先落下插地，爱音从空中落地、伸手拔剑，随后交战。开场不可被玩家打断。
- 五芒剑庭：五条星边、15 把实体剑，落点圈与光柱提前标出危险位置。每把剑有独立延迟；剑庭释放后接三折追星，爱音继续近战。
- 重击起手可触发真实无敌侧闪；侧闪结束后检查障碍，再移至玩家背后，以独立前摇发动反斩。
- 正面轻击可被架剑格挡并震退；重击或绕背能破守。
- 双刀扇面发射七道飞刃；离弦招式可移至已发射飞刃附近继续连斩，位移会检查墙体。
- 其他招式包括低位半月、延迟交叉剑痕、七拍双刀、五角星牢、点名落剑、切线飞刃与双剑回收。
- 允许读取主机已收到的轻击、重击、闪避、喝药输入，按距离和当前场地状态选择反制；技能轮换记录已用槽位，防止一直抽到同一组招式。

|---|---|
| 菲比 | 前推的压缩火拳、放射拳雨、六瓣日印；保留拳、膝、踢、擒拿各自接触动作 |
| 糯糯 | 延迟月影回声，16 种独立落点排列：夹心、三角、四象、逆序、八卦、棋盘、螺旋等；蓄力时横向游走 |
| 塔菲 | 点射、狙击、跳弹、火箭、可拆地雷、双哨交火、五点布雷；废除多个空中槽共用同一滑铲的替代招式 |
| 香企鹅 | 推进冰脊、三岔冻土、四象冰棱、实体冰晶，以及飞锤、滚冰、牵引重锻 |
| 娅娅 | 双结收丝、三结牵月、对角缝合、四角归丝；配合牵引、可斩断丝路与旋臂长鞭 |
| 凑企鹅残躯 | 延迟断羽切线、三重审判剑痕、点名羽墓与残月羽域；保留独立高压读指令及联机击杀成长 |

所有人形 Boss 的 112 个技能槽有不同名称。通用的移动、近战基础判定和动画驱动继续共享，专属场地攻击使用独立轨迹与状态。

## 美术与复查

Blender MCP 原创模型：`SignatureSword.fbx`、`SignatureCrystal.fbx`、`SignatureFeather.fbx`。源文件在 `ArtSource/SignatureCombat/SignatureCombat.blend`。没有改写原有 Blender 场景文件。

新柔光着色器 `SignatureEnergy.shader` 用于核心亮线、柔光外层及落剑光柱。普通闪避增加螺旋气流、碎光和连续烘焙残影；玩家火龙、回旋剑与樱花招式增加附加光丝。临时轨迹和危险物采用固定容量池。

验证入口：

- `Tools → Tomorin → Validate original boss signatures (Play Mode)`：所有槽位执行、Mirror 序列化、受击及死亡清理、开场、剑雨、读指令、格挡震退与背斩。
- `Tools → Tomorin → Validate sword garden over TCP (Play Mode)`：从 InkStart 运行，独立 Telepathy 客户端验证真实 TCP 消息。
- `Tools → Tomorin → Verify stamina rewards (Play Mode)`：从离线 AshenCourt 运行。

记录：`Logs/Trial/SignatureValidation.txt`、`SignatureNetworkValidation.txt`；剑庭与落剑预览为同目录的 `AnonSwordGardenPreview.png`、`AnonSwordImpactPreview.png`。预览使用手动推进攻击时钟的固定镜头，持续光迹会叠加，并不代表正常游戏中的同帧特效密度。

最终 Unity 编译通过，专属招式运行回归通过 412 项；真实 TCP 验证通过 9 项。控制台没有游戏运行错误。
