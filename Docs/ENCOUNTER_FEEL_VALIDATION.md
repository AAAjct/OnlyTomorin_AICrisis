# 庭院、竞技场与战斗手感

本轮实现日期：2026-11-02。Unity 6000.3.27f2，使用项目原有 Mirror / Telepathy、Input System 和 uGUI，不新增运行时包。

## 玩法

- 开始页「单人游玩」打开关卡列表，仅有「庭院 (Boss · 大肥鱼)」。联机通过下拉入口打开同款列表：竞技场第一，庭院第二。庭院从南侧入口开始，清理三名守卫后开启 Boss 门。
- 竞技场至少两人，玩家互伤、锁定、格挡、弹反、击杀计分和 3 秒重生；重生保护 2 秒，主动攻击解除。本人昵称与生命放在左上角，只有其他玩家显示头顶昵称和生命。
- 不设房间人数上限。Boss 最大生命为 `1400 × 当前房间人数`；人数变化保留生命百分比，死亡不会被人数变化复活。Boss 韧性随人数增加，伤害增幅最多 25%，Boss 词条再做小幅调整。较大房间的名册和世界快照会分片发送，避免超过 TCP 单条消息大小。
- 非竞技场每位玩家入场三选一：气血 +20、伤害 +12%、气力 +15、闪避消耗 -4、灵露治疗 +12 或架势伤害 +15%。Boss 随机获得减伤 8%、伤害 +8% 或技能速度 +6% 中的一项。选择由房主校验，重生保留，重新挑战重选。
- 大肥鱼新增二连摆尾、折返冲撞、延迟重砸和双轮全队点名。55% 以下觉醒，25% 以下狂潮并连续变招。前扫范围为前方 220 度，回身扫范围为后方 220 度；沿可见水刃扫过的角度命中，不再起手就击中整个扇区。
- 翻滚无敌期间前 0.24 秒内躲开来招后，3 秒内下一次普攻变为带虚影的闪身横斩，基础伤害 42（普通一击 28）。位移遵循角色碰撞，并在目标身前减速，避免穿过敌人。
- 格挡起手 0.20 秒内可完美弹反。扫尾、冲撞和折返冲撞可触发反斩，衔接动作、短慢放、金色斩光、冲击环和手柄震动；反斩有 3 秒冷却。范围砸地和水环仍须闪避。
- 命中、重击、斩杀、格挡与弹反有不同的顿帧、镜头脉冲、火花与音色。普通敌人受击后退，沿受击方向快速倒地。庭院弦音和战斗鼓点采用原创程序合成并交叉淡入淡出。

## 扫尾下陷与基础耐力修正

新 FBX 根节点带约 -90° X 轴导入旋转。回身扫尾原先将转身旋转右乘到该旋转，实际绕倾斜后的模型局部 Y 轴翻转，后半段整个网格进入地下。现改为在角色空间绕竖直轴左乘转身旋转，保留导入姿态、攻击轨迹和技能时序。

`Tools/Tomorin/Verify tail sweep grounding (Edit Mode)` 在隔离预览场景中，分别采样普通扫尾 / 二连扫尾、觉醒前 / 觉醒后共 404 个姿态，烘焙蒙皮并检查所有顶点高度。修复前可稳定复现最低 -2.834 m；修复后全部采样未进入地面。Unity 编译通过。

玩家基础耐力统一为 `TrialPlayer.BaseStamina = 180`，即原 120 的 1.5 倍。初始化、增益选择和重置共用该常量，「定心」仍额外增加 15 点至 195；重生按当前最大耐力回满，联机快照沿用最大耐力字段。消耗和恢复速度保持原值。已有 Play Mode / TCP 验证工具新增耐力断言，供后续完整回归使用；上述 91 项为前次功能迭代的验证记录。
