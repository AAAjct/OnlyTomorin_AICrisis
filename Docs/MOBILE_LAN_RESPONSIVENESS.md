# 肥鱼、局域网和手机操作调整（2026-11-03）

- 修复肥鱼追踪时先降低、再提高行走权重导致每帧互相抵消的问题。沿用原模型腿、膝盖和手臂的程序动画，移动权重继续随角色快照同步。
- 将“会分裂的波浪”按深渊点名的双轮落潮处理：两人及以上只保留第一轮点名与冲击波，单人保留两轮。多人施法时长至少 3.6 秒（疾流词条仍有 6% 加速），避免人数和狂暴同时压缩躲避窗口。点名波速从 5.2 降至 4.6，涡流波速从 7.8 + 0.8n 降至 7.0 + 0.65n，二阶段冲击波基础伤害从 25 降至 22。
- 主机世界快照目标频率从 30 Hz 提至 60 Hz；输入和快照发送保留计时余量，避免每帧重设截止时间被帧抖动量化到更低频率。本机角色位置平滑时间常数从约 45 ms 缩短至约 17 ms，其他角色约 33 ms。没有远端就绪玩家时跳过快照分配。继续使用 Telepathy TCP 和已有 NoDelay 配置，战斗判定仍由主机负责。
- 手机启动时显式请求 60 FPS，主菜单和暂停菜单共享“手机帧率”选项，循环 60 / 90 / 120 / 跟随屏幕并保存。实际可用帧率取决于屏幕刷新率、系统调度及设备负载。桌面帧率不受此选项影响。
- 移动触控区扩展到安全区域左半屏，采用浮动摇杆；手指从移动区域按下后一直归该区域管理，拖出摇杆也不会转视角。右侧另一根手指可同时转视角。忽略移动端原始触摸/模拟鼠标视角，避免同一手指被重复处理；松手、失焦、关闭控件均清理输入。
- 手机粒子数量降至原来的约 55%，连续残影网格烘焙间隔改为 120 ms，关闭场景 Bloom，并按 12 米网格及材质合批静态场景，允许视野外区域被剔除。保留现有手机渲染管线和项目设置中的用户修改。

## 验证

Unity 6000.3.27f2 Editor 编译无错误。

`Tools > Tomorin > Verify boss scaling and LAN arena (Play Mode)`：55 项通过，包括真实 TCP 参与者、五人房间、加入退出、肥鱼移动权重和真实腿骨变化、1/2/3 人波浪次数、双指移动与视角隔离。

`Tools > Tomorin > Verify combat networking (Play Mode)`：23 项通过，覆盖主机、真实远端客户端、输入边沿、弹反反馈、快照和断线。

`Tools > Tomorin > Verify shared settings and rebinding (Play Mode)`：41 项通过，包括帧率选项循环保存、主菜单与暂停菜单布局一致、键鼠/手柄改键及暂停恢复。设置布局已检查渲染截图；测试已补上开局增益选择这一步。

详细运行记录在 `Logs/Trial/BossArenaValidation.txt` 和 `Logs/Trial/CombatNetworkValidation.txt`。上述联机检查使用本机独立 TCP 端点，并非两台设备的局域网延迟测量。未连接手机实测 CPU/GPU 帧时间、温度或续航，也没有据此宣称固定帧率提升或局域网延迟已降至某个数值。
