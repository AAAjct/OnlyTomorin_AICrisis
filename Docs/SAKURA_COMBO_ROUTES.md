# 樱花散新增入口

轻 = 轻击，重 = 重击。以下路线最后一击触发樱花突刺与樱花散：

| 输入 | 入口 |
| --- | --- |
| 轻 → 轻 → 重 | 保留原入口 |
| 轻 → 重 → 重 | 新增：反向斜劈后接樱花突刺 |
| 闪避 → 重 → 重 | 新增：翻滚一闪后接追击樱花突刺 |
| 轻 → 轻 → 轻 → 轻 → 重 | 新增：回旋终结后接追击樱花突刺 |
| 重 → 重 → 重 → 重 | 新增：重劈终结后接追击樱花突刺 |
| 空中光刃连段 → 落地 → 轻 | 新增：斜向俯冲 / 垂直插剑落地收招后接樱花散，可提前预输入轻击 |

原有蓄力下劈、影返交错接重击的樱花派生继续保留。新入口使用原有樱花散战斗事件、移动判定、伤害和音效；连招提示直接从分支表读取。追击樱花突刺后仍可接轻击交错斩，或重击挑空抽刀；释放输入正常收招。

`Tools/Tomorin/Verify readable combo flow` 包含新增路线在 30 / 60 / 144 FPS 步长下的真实输入、提示、单次释放、Mirror 快照和松手收招检查，并保留全部路线无循环与有界收招的检查。

最后一道光刃结束后顺势下降，不再悬停等连段窗口过期。斜向俯冲继承下降速度，取消额外悬空起手。自然落地和两种俯冲都以真实碰撞确认触地；预输入轻击经过约 25 ms 的落地压身即可进入樱花散，无需等完整收招或经过站立状态。前冲惯性、提刀姿态和骨骼过渡同步衔接，松手则约 160 ms 完成落地收势。

短收势后仍保留 0.75 秒的轻击续接窗口。窗口过期恢复普通起手，闪避取消窗口；落地后重击保持普通重击起手。快照新增落地进度、樱花顺接和光刃下降状态，使客户端使用相同的动作过渡。
