# 耐力、角色能力与角色显示调整（2026-11-03）

## 玩法

- 玩家基础生命 200、耐力 280，定心后耐力 295。
- 轻击 / 重击 / 闪避消耗 15 / 28 / 20；轻身闪避消耗 16，疾跑每秒消耗 5。
- 消耗后的自然回复等待 0.32 秒；移动、站定、持续格挡每秒分别回复 62 / 84 / 20。
- 有效命中回复 6，击杀回复 45；完美闪避每次动作最多回复 40；弹反支付 8 后回复 30。
- 喝药同时回生命和补满耐力，满血缺耐力可以喝药；生效前受击打断不扣药。
- 基础伤害 34，轻击 / 重击架势伤害 26 / 56；移动 / 疾跑速度 5 / 8；普通受击硬直 0.32 秒。
- 维持房主权威计算，快照继续携带生命、耐力上限和当前耐力。

## 模型与材质

- 菲比、糯糯、娅娅从多套重复骨架中按可见手掌位置选择骨架，替代按头部中心选择。
- 菲比、糯糯手掌使用完整手骨权重，避免掌部混入袖口、躯干或头部权重；降低待机防御手位。
- 娅娅长发、发辫和饰品跟随头骨，裙装中央保持连续；重建三名角色的蒙皮、预制体和动画预览。
- 为修复后的蒙皮设置与模型根坐标一致的剔除范围。
- 新建 Assets/Art/Champions/ChampionGun.mat，使用 URP/Lit 与原 Textures_Guns 图集；仅覆盖战斗枪械实例，保留第三方原文件。

- 飞行技能线、鞭身使用带编织纹理与透明边缘的 URP 粒子材质，保留碰撞与预警几何；场景销毁时回收生成材质和纹理。
