# 黑色猩红月牙与连招续航

## 效果与数值

- 月刃、空中赤刃使用等半径圆弧，主体为近黑色弯月，猩红发光外沿与尖端流光。空中版本在圆弧平面内倾斜。
- 拖尾采样过去 0.26 秒的实际直线飞行路径，形成黑红渐隐面与双尖端流光。碰墙后停止前进并消散，对象池复用时重置可见性，销毁时释放网格。
- 原先 `Pow(Sin(u * PI), 0.75)` 在末端会对微小负数求非整数次幂，产生 NaN。端点现在显式为零，其余输入钳制为非负；提交顶点前检查有限值。固定三角形索引仅在初始化时上传。
- 基础耐力 420 → 630；轻击 15 → 12，重击 28 → 22，处决 40 → 32，闪避 20 → 16；轻身闪避 16 → 12，保留四点优惠。
- 命中回耐 6 → 10；静止／移动／防御回耐为每秒 165／120／40。消耗后延迟 0.18 秒恢复，轻重攻击中以每秒 18 缓慢回耐。闪避、受击、喝药、蓄力期间不享受攻击回耐。完美闪避、格挡与击杀奖励沿用原值。
- 重生、定心增益、主机权威状态和 HUD 共用基础耐力与最大耐力字段。
