# 长按连招、格挡变招与追剑收斩

L 为轻击，H 为重击，G 为格挡。点按和长按共用相同的路线。长按会在每一招的续接窗口读取下一招，松开便停止续招；完成终结招的收势后，持续按住可重新起手。长按不会预先积压后续攻击。闪避、受击、喝药会中断持续攻击，松开再按可恢复。

## 基础路线

| 操作 | 效果 |
| --- | --- |
| 长按 L / 点按 L L L L | 挑斩 → 横斩 → 直刺 → 回旋终结；地面四连 |
| 长按 H / 点按 H H H | 横劈 → 反向上挑 → 重劈终结；重击三连 |
| L H / L L H / L L L H | 反向斜劈 / 樱花突刺 / 后撤三月刃 |
| Ctrl 后长按 L | 小跃 → 空中交错 → 空中回旋 → 三飞刃 → 俯冲落地 |
| 空中按 H | 三飞刃，再 H 插剑落地 |
| 翻滚后 L，继续 L | 前刺 → 交错斩 → 柄击 → 扫腿 |
| 交错斩 / 扫腿后 H | 挑空，再接近身空中动作或三飞刃 |

普通长按 H 直接执行重击连段。原有蓄力下劈改为第二重击后按 G 直接发动；完美格挡的长按火龙蓄力保留。轻重切换时优先执行新的点按命令。两个按钮同时按住时延续最近点按的按钮。

## 格挡本身就是变招

连段中按 G，立即进入实际格挡，约 0.14 秒后自动执行派生，不需要再补按 L / H。快速 L,L,G 与分开点按相同；格挡会立即响应，并按已输入的轻击段数选择派生。格挡准备期间若受到攻击，仍按朝向、气力和完美格挡窗口结算；实际完美格挡会取消普通派生，保留强化选择。

| 格挡之前的节点 | 直接派生 |
| --- | --- |
| 第二轻击、交错斩、绕身回刀、回身横扫、二连斩 | **投刀回旋** |
| 第一轻击及其他普通起手 | 交错斩，再 L 柄击 / H 挑空 |
| 直刺、樱花突刺、翻滚前刺、穿针 | 月刃追刺，再 L 影返 / H 踏空 |
| 第一重击、扫腿 | 挑空抽刀，再接空中连段 |
| 第二重击 | 蓄势下劈，再 L 上挑 / H 樱花突刺 |
| 回旋终结、第三重击、落地抽刀 | 低跃翻身，再 L 腾身横扫 / H 空中三飞刃 |
| 蓄势下劈 | 樱花突刺 |
| 柄击等身体招式 | 贴身肘击，再接绕身或纳刀 |
| 空中交错、回旋等近身动作 | 蹬墙借步，再接飞刃或插剑落地 |
| 空中飞刃 | 浮空穿针，再接腾身或三飞刃 |

G 的小光圈只是转招提示，已缩小轮廓；真正派生包含角色动作、位移、伤害和后续路线。按住 G 不会反复发动，需要松开再按。闲置时 G 仍是普通格挡。非终结招收招后的 0.55 秒窗口也接受 G。

## 投刀 → 追剑 → 收剑斩

飞剑沿角色出手时的正前方投出，固定 12 米，不会朝锁定或附近敌人修正；沿真实螺旋路径向前并返回，持续约 1.15 秒，具有墙体遮挡与扫掠伤害。同一发对同一目标只结算一次。

投刀离手约 0.1 秒后、飞剑仍在飞行时按 L 或 H：

1. 主机读取飞剑当时的真实位置。
2. 角色瞬移到飞剑下方的落点；完整角色胶囊体扫掠会阻止穿墙。
3. 取消飞剑后续飞行与伤害，将剑归还手中。
4. L 执行「追剑收斩」：一次近身横斩，基础伤害 48、消耗 12 气力。H 执行「追剑升龙」：在剑的落点升空约 2.2 米，基础伤害 52、消耗 14 气力。
5. 横斩后 L 接交错、H 接挑空；升龙后 L 接腾身横扫、H 接空中三飞刃。

点按 L / H 可提前追剑；持续按住 L / H 会在正常续接窗口进入对应追剑招式。松开停止续招。飞剑撞墙、返回完成或当前没有飞剑时，不会凭空瞬移。追剑不额外赋予无敌，敌人护甲、格挡和祝福倍率继续生效。

练习路线：

- L L G → 投刀回旋 → L 追剑收斩 → L 交错 → G 再投刀。
- 翻滚 L → L 交错 → G 投刀 → L 追剑收斩 → H 挑空 → H 飞刃 → H 落地。
- 直刺 G → 月刃追刺 → L 影返 → H 樱花终结。
- 重劈终结 G → 低跃 → L 腾身 → L 剪脚 → L 落地抽刀。

## 完美格挡

完美格挡仍提供 5 秒内一次强化选择：L 三连刺，H 火龙（可长按蓄力），闪避远闪。三连刺可接影返交错、踏空回斩；火龙可接追刺或回旋刀。回旋刀也支持新追剑收斩。影返有两次实际接触，踏空实际升高约 2.2 米。每一步均可按正常规则防御取消。
