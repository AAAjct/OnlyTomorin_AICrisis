# 主角轻击与重击衔接

每次点按轻击推进一段；停止输入后收招。地面前三段保留目标追击和墙体阻挡。

| 轻击段数 | 招式 |
| --- | --- |
| 1 | 朝前从左下挑向右上，刀光保持在正面 |
| 2 | 腰高横刀，向前方划半月弧 |
| 3 | 人保持直立、刀水平，呈 `|-`；向前突刺再转身收势 |
| 4 | 空跃，实际升空约 2.15 米，无伤害 |
| 5–7 | 每次轻击发射一道暗红远程斩，合计三道；浮空保持 |
| 8 | 向前斜下冲击，落地造成范围伤害，向周围发射十二道暗蓝沙石 |

| 输入 | 重击分支 |
| --- | --- |
| 一轻 → 重 | 从第一刀收势反向斩出更大的斜劈 |
| 二轻 → 重 | 朝锁定的起手方向突进约 6 米；真实起终点间铺开缺口花瓣、螺旋花带和交错斩痕，沿路造成伤害 |
| 三轻 → 重 | 先后撤约 4.2 米，再依次发出三道圆弧月刃 |
| 四轻 → 空中重击 | 原地剑尖朝下，垂直下落，落地产生飞沙射影与暗蓝沙石 |
| 插剑落地 → 轻 | 向前突刺约 6.8 米，真实起终点之间释放樱花散 |
| 空中远程斩 → 重 | 提前收束空中段，进入插剑下落 |

连段恢复结束后仍保留 0.55 秒衔接窗口；立即接招和收招后接招使用同一套分支。按键按输入顺序保留最多两次后续攻击，因此快速点按“轻、轻、重”会先完成第二段轻击，再进入樱花突刺。命中停顿不会消耗输入的等待时间；开始下一招只消费对应的一次输入。闪避、格挡取消、受击、喝药和重置会清掉尚未执行的攻击。联机同帧到达的多个输入包按顺序处理，重复轻击不再被位运算合并。

空中不继续输入会在窗口结束后落下。下冲落地后接攻击；所有剑招（包括空中下冲、火龙翻滚和回旋刀）均能在起手约 45–75 毫秒后衔接格挡或闪避，取消空中招式后恢复正常重力。闪避约 0.1 秒后可转格挡。

## 追加衔接路线

新增回身横扫、进步上挑、月刃追刺三种动作，消耗与其他轻 / 重击相同，不额外发放无敌或强化。

| 输入路线 | 后续效果 |
| --- | --- |
| 二轻 → 重（樱花突刺）→ 重 | 收回刺出的剑，接回身横扫 |
| 樱花突刺 → 轻（收刀斩）→ 轻 | 接交错斩，进入低扫、二连与小跃路线 |
| 收刀斩 → 重 | 接回身横扫 |
| 回身横扫 → 重 | 接向前踏步的进步上挑 |
| 进步上挑 → 轻 | 接空跃，再接空中三斩或重击下落 |
| 进步上挑 → 重 | 接后撤三月刃 |
| 三轻 → 重（三月刃）→ 轻 / 重 | 三道月刃完成发射后接 4.4 米月刃追刺 |
| 月刃追刺 → 轻 / 重 | 接收刀斩 / 回身横扫，重新进入地面连招 |
| 插剑或斜冲落地 → 轻 / 重 | 接落地樱花突刺；再重接回身横扫 |
| 反向斜劈、回旋重斩、截击 → 轻 | 接回身横扫 |
| 蓄力下劈、翻滚跳劈、后跃火龙 → 轻 | 接进步上挑 |
| 火龙、回旋刀 → 轻 / 重 | 发射后接月刃追刺，已发射的招式继续飞行 |
| 格挡三连刺、背闪突刺 → 轻 / 重 | 接收刀斩或相应突刺 / 横扫分支 |

所有衔接继续使用角色碰撞器移动，追刺会被墙体阻挡。重击按招式各自的攻击结束点开放续接，三连刺、三月刃、火龙与落地招式保留最后一次出手。显示层用 0.11 秒从上一帧的手部、剑向和模型根姿势过渡到下一招；剑始终贴合最终平滑后的持剑手。

## 完美格挡强化

完美格挡后保留一次强化选择，持续 5 秒；不再强制自动反斩。气力不足不会消耗强化。

| 下一步输入 | 招式 |
| --- | --- |
| 轻击 | 三连刺，三次独立命中和刺光；单刺基础伤害 32 |
| 重击 | 向后翻滚并沿半圆绕至侧面，再释放火龙；火龙沿路径扫掠敌人 |
| 按住重击 | 蓄力后释放火龙；1.4 秒满蓄自动释放，射程从 9 米升至 24 米，基础伤害从 65 升至 155，上限封顶 |
| 闪避 | 原闪避距离的 2 倍；获得 3.5 秒内一次追击选择 |
| 强化闪避 → 轻击 | 最多 16 米瞬闪至敌人背后再突刺，墙体会阻挡，起手有短暂无敌 |
| 强化闪避 → 重击 | 投出旋转刀，沿螺旋路径飞向敌人再回到主角手里；单目标只结算一次，基础伤害 85 |

火龙与回旋刀使用真实扫掠碰撞；防御取消后已发射的攻击继续完成。敌人的现有护甲、格挡、祝福和硬直倍率仍作用于伤害。翻滚、蓄力和突刺可以继续衔接闪避、格挡。

完美闪避保留轻击闪身横斩，新增重击分支：实际向后跳跃约 4.2 米、升高约 1.8 米，下落落地后再向前下劈并释放一道火龙。空中不会提前发射；跳跃和劈斩均可衔接闪避或格挡。该分支火龙基础伤害 110、射程 16.5 米。完美格挡强化远闪的追击分支仍优先使用背闪 / 回旋刀。

远程斩、月刃、沙石均有实际飞行速度、寿命、扫掠碰撞和墙体遮挡。同一发对同一目标只结算一次；远程伤害独立于近战剑身判定。樱花散与落地冲击各只触发一次。

三轻接重发出的三道月刃与空中远程斩统一使用猩红剑气：黑色圆弧刃体、HDR 猩红细刃缘、柔化红色光晕及散墨拖尾。颜色不再使用樱花粉或偏白刃缘；伤害、飞行速度、寿命和碰撞范围保持原值。

跃起、回转、下落与落地追加动作特效：

| 动作 | 表现 |
| --- | --- |
| 空跃、跳劈、完美闪避后跃 | 从真实起跳点升起两道猩红螺旋光带，足下有向外散开的细光环和火星 |
| 第三轻击转身、回身横扫、反向重扫、火龙翻滚、闪避回风斩 | 随主角位置移动的宽弧刀光，辅以交错细光丝和较低的回旋环 |
| 插剑下落、空中斜冲、后跃落劈 | 从起落路径收束到主角身上的螺旋剑芒，地面显示小范围落点光环 |
| 插剑或斜冲落地、跳劈和后跃着地 | 向外展开的双层冲击环与八瓣余光；原有暗蓝飞沙和实际伤害保持独立 |

每次动作在对应阶段只发送一次特效事件，主机和客户端按同一事件播放；附着的跃起 / 回转 / 下落光带在格挡、普通闪避或硬直取消后停止。几何、光带和材质使用有上限的复用池。

初始数值：暗红斩每发 35 伤害，月刃每发 28，樱花散 24；轻击下冲 60、重击下落 72，沙石每发 12，均叠加现有祝福倍率。地面近战仍沿用原有伤害与气力逻辑。

保留闪避衍生、基础重击连段、蓄力、格挡反击、完美闪避等原有操作。命中停顿只在实际接触时触发。

联机：主机模拟位移和伤害；角色快照同步招式编号、实际高度、蓄力值和强化剩余时间；战斗事件同步路径两端、方向和强度，让樱花、火龙、回旋刀在所有客户端保持同一路径。

编辑器验证入口：`Tools → Tomorin → Verify ordered sword combo`，结果为 `Logs/Trial/SwordComboValidation.txt`。原有综合回归入口为 `Verify requested combat polish`。

## 追加翻滚、小跃与飞刃连招

在前八段原有轻击之后，可接落地樱花突刺、收刀斩、交错斩、低扫、二连斩、回旋终结、小跃，进入第二条空中路线。每段都需要输入，停按后会收招并恢复重力。

| 输入 | 新动作与后续 |
| --- | --- |
| 普通翻滚开始 0.10 秒后 → 轻 | 取消翻滚，朝角色正前方突刺 4.8 米；再轻接交错斩，再重接一闪 |
| 普通翻滚中 → 重 | 取消翻滚，从右后下方横斩到正前方，追加一道月刃；轻接低扫，重接小跃 |
| 收刀斩 / 翻滚突刺 → 连轻 | 交错斩 → 低扫 → 二连斩 → 回旋终结 → 小跃 |
| 低扫 → 重 / 穿针突刺 → 重 | 小跃并悬停在离起跳地面约 1.25 米处 |
| 小跃 → 连轻 | 空中交错斩（两飞刃）→ 空中回旋（两月刃）→ 三连飞刃 → 斜冲飞沙落地 |
| 小跃 / 空中交错 → 重 | 后翻借步；正前方 1.7 米内有墙则沿墙面法线蹬开约 3.2 米，角色控制器仍处理碰撞 |
| 后翻借步 → 轻 / 重 | 三连飞刃 / 插剑下落 |
| 空中回旋 → 重 | 提前进入三连飞刃；三连飞刃 → 重可提前选择插剑落地 |
| 回旋终结 → 重 → 轻 | 后撤抽刀 → 穿针突刺 → 轻接交错斩 / 重接小跃 |
| 三段重击 → 重 | 回旋终结；轻回地面交错斩，重接后撤抽刀 |

十个地面节点穿插飞刃：交错斩、翻滚一闪、后撤抽刀、穿针突刺、回身横扫、进步上挑、月刃追刺、收刀斩各发一道；二连斩和回旋终结各发两道。空中交错与回旋各两道，三连飞刃三道，后翻借步一道。插入飞刃基础伤害 18，二连斩及空中三连单发为 14；沿用原有敌人防御、祝福和扫掠碰撞。未到发射点就取消不会出刃，已经发射的飞刃继续完成。

普通翻滚与小跃没有额外无敌。翻滚派生立即结束翻滚无敌；完美闪避、完美格挡强化仍优先选择原有强化招式。小跃、空中剑招和蹬墙借步均可接格挡或闪避，取消后恢复重力，不会持续悬空。移动不穿墙，不会无条件攀墙。

刀光现在采用黑色等半径圆弧刃体、细猩红发光刃缘、噪声羽化的内缘与散墨粒子；普通翻滚残影约 0.18 秒、淡墨，完美闪避约 0.38 秒、浓墨并逐渐侵蚀消散。完美弹反加入浓墨爆散、猩红与金色交错斩痕、金属撞击低音、约 0.12 秒命中停顿、约 0.22 秒衰减振刀震动及手柄反馈。减少动态效果设置继续限制镜头震动。

## 格挡织招、长按变化与追踪

- 剑招中插入格挡，会保存 0.85 秒变招窗口；接轻进入反架针刺，接重进入散华扇刃。空中插格挡后可接浮空穿针或空中回旋。实际受到攻击时仍按原有方向、气力与完美格挡窗口结算。
- 短按保留现有路线。连招中轻击持续按住约 0.26 秒，会追加一次蓄势穿针；重击持续按住约 0.30 秒追加一次风轮。空中长按轻进入浮空穿针，长按重进入三飞刃。一段持续长按只追加一次派生，松开后才可再次触发。完美格挡后的火龙蓄力与强化路线保持优先。
- 新节点可继续互通：蓄势穿针→轻交错 / 重风轮；风轮→轻小跃 / 重后撤；反架针刺→轻二连 / 重散华；散华→轻穿针 / 重小跃；浮空穿针→轻空中回旋 / 重蹬墙借步。
- 锁定优先选择 Boss，接触阶段持续修正面向和位移方向。未锁定时扩大近身辅助选敌扇面；前冲按敌人体型与实际距离减速，减少冲过 Boss 后背和朝空处挥刀。墙体仍限制移动和伤害。
- 按招式选择六套色调：黑刃猩红、青蓝风刃、玉色流光、鎏金刺芒、紫色回旋、月白风轮。飞刃保留圆弧墨刃，新增螺旋细丝、散华花瓣阵、风轮环与变招符纹；颜色样式随事件一起联机同步。小跃与空中回旋、格挡变招和蓄势招的轮廓也有所区别。

## 最新近身动作扩展（替代逐刀飞刃的密集循环）

新增十个身体动作：剑柄击、转胯扫腿、低跃过身、腾身横扫、绕身回刀、落地抽刀、贴身肘击、空中剪脚、纳刀转身和云回挑斩。各自有真实接触节奏与根节点姿态；绕身回刀与纳刀沿弧线侧移，低跃带完整前翻，空中剪脚有两次独立接触。均不附加瞬移或无敌。

- 交错斩后连轻：剑柄击 → 扫腿 → 低跃 → 腾身横扫 → 空中剪脚 → 云回挑斩 → 落地抽刀 → 收刀斩 → 交错斩。
- 剑柄击 → 重：肘击；肘击 → 轻：绕身回刀 / 重：纳刀；绕身 → 轻：纳刀 / 重：低跃；纳刀 → 轻：柄击 / 重：云回挑斩。
- 低跃 → 轻：腾身横扫 / 重：空中剪脚；腾身横扫 → 重：落地抽刀；空中剪脚 → 重：腾身横扫；云回挑斩 → 重：插剑下落。
- 蓄势穿针 → 轻：低跃；反架针刺 → 轻：柄击；浮空穿针 → 轻：腾身横扫。原有空中扇刃路线仍可选择。
- 普通空跃、小跃和低跃：统一 **5 气力**，即使从重击分支触发也不按 22 点收费；蹬墙借步 **6 气力**；近身空中招式轻 / 重为 **7 / 10 气力**；身体招式 **6 气力**；地面近身刀招轻 / 重为 **9 / 14 气力**。格挡强化的特殊攻击仍使用原有费用。
- 自动穿插飞刃缩减至专门节点：翻滚一闪、月刃追刺各一道，回旋终结两道，散华和空中扇刃三道。交错、二连、上挑、后撤、穿针和普通空中交错 / 回旋改为近身动作，不再每刀追加飞刃。原有三月刃与高空远程斩保留。
- 特效改为贴着身体动作的短迹：柄击 / 肘击的金色碎火星、扫腿尘墨、低跃羽迹、剪脚双弧、绕身刀痕、落斩斜线与纳刀细芒，减少大面积重复半月。

## Ctrl 跳跃起手

左 / 右 Ctrl 默认触发小跃（手柄 Y / △），消耗 5 气力，可在设置中改键。地面剑招和翻滚可衔接跳跃，空中不能反复起跳。

- Ctrl → 轻击 → 轻击 → 轻击 → 轻击：小跃 → 交错 → 回旋 → 三飞刃 → 俯冲。
- Ctrl → 重击：小跃 → 蹬墙借步，随后可接轻击三飞刃或重击插剑下落。
- Ctrl 与轻 / 重击一起输入时，攻击预输入会保留至空中衔接；格挡、闪避仍优先。

## 增加挑空与空中飞刃入口

交错斩、扫腿、蓄势穿针后按重击，可进入新的挑空抽刀（5 气力，实际升高约 1.7 米）。挑空后轻击接腾身横扫，重击直接进入空中连发飞刃（9 气力、三道独立飞刃）。腾身横扫、空中剪脚、普通空中交错、空中回旋与浮空穿针后重击也能接三飞刃。飞刃完成后，轻击接云回挑斩重返近身路线，重击插剑落地。普通近身动作不会因此每刀自动出刃。
