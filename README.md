# 只鹅 · 智械危机

一个以凑企鹅 Tomorin 为主角的第三人称剑术动作游戏原型。从水墨庭院挑战「大肥鱼 · DeepSeek」，或进入角色 Boss 挑战、无尽生存与 Boss 连战。支持单人、Mirror 多人合作和竞技场自由决斗，联机提供 TCP 直连、Unity Relay 房间码与公共房间。房间默认 8 人，可设置为 2–16 人。由 GPT6.1Sol 开发。

资源目录说明：[资源分类与放置规则](Docs/ASSET_ORGANIZATION.md)。

## 运行项目

- Unity **6000.3.27f2**，URP **17.3.0**，Input System **1.20.1**。
- 使用上述 Unity 版本打开项目，等待依赖导入与脚本编译完成。打开 `Assets/Scenes/InkStart.unity`，点击 Play，从「单人游玩」或「多人联机」开始。
- 单人及合作选关包含七个 Boss 关卡，以及「无尽雾潮 · 肉鸽生存」「百战之庭 · Boss 连战」；联机额外提供竞技场。场景与模式见下表。
- 庭院始终从入口开始，先打三名守卫。入场时每名玩家从三个随机增益中选一个，Boss 同时获得一项小幅随机增益；竞技场不启用增益。
- `Assets/Scenes/AshenCourt.unity` 是战斗场景；直接运行该场景时会显示试炼菜单。
- 角色挑战包括双生莲庭（菲比、糯糯）、绯刃天台（爱音）、霓虹枪港（塔菲）、冰海熔炉（香企鹅）、月丝星台（娅娅）。每个角色有 16 招；完整技能与应对见 [Boss 关卡设计](Docs/CHAMPION_STAGES.md)。
- 断羽终庭（`Assets/Scenes/PenguinRemnantSanctum.unity`）迎战「凑企鹅残躯 · 断羽无赦」。残躯根据玩家已发生的动作作出反制，出招期间自身架势暂停自然衰减。该战没有濒死保护，联机中残躯每次击杀玩家都会强化，持续至本轮结束。
- 左侧香炉可恢复生命、气力和药瓶，并设置本局重生点；休息会重置敌人。
- 正常流程必须击败三名奶蛙，左右围栏防止绕开封印。进入庭心后，圆形斗场入口封闭，击败 Boss 或重新开始后解除。

场景均位于 `Assets/Scenes/`，从开始菜单选择即可进入。

| 绯刃天台 | `CrimsonSwordTerrace.unity` | 爱音，连续拼刀与架势攻防 |
| 霓虹枪港 | `NeonBallisticsHarbor.unity` | 塔菲，实体弹道、掩体与换弹 |
| 冰海熔炉 | `GlacialForge.unity` | 香企鹅，重锤与扩散冰环 |
| 月丝星台 | `MoonSilkObservatory.unity` | 娅娅，长鞭与内外安全区 |
| 断羽终庭 | `PenguinRemnantSanctum.unity` | 凑企鹅残躯，行为反制与联机击杀成长 |
| 无尽雾潮 · 肉鸽生存 | `EndlessMist.unity` | 持续刷怪、经验升级与词条构筑 |
| 百战之庭 · Boss 连战 | `BossGauntlet.unity` | 依次击败八位 Boss，药瓶限量 |

- **无尽雾潮**：敌人随波次增强，每 5 波出现精英 Boss；击杀获得经验，升级后可打开升级界面，从随机提供的三个词条中选择一个。共 30 种词条，涵盖属性、恢复、范围攻击和元素效果，部分可重复叠加。
- **百战之庭**：八位 Boss 逐个登场。初始只有 3 瓶药，战后恢复生命与气力，但不补充已消耗的药瓶。
- **装扮**：主菜单可开关斗笠与口罩，并选择初始剑或「鸣霜」，提供模型预览并自动保存选择。

## 关卡难度与移动喝药

- 单人及联机关卡列表顶部可选择「简单 / 正常 / 困难」，默认正常。先选难度，再点关卡；联机由房主选择，房间列表显示所选难度。
- 简单：敌人生命 ×0.75、伤害 ×0.70；正常：现有数值；困难：敌人生命与伤害均 ×1.30。与联机人数倍率叠加，适用于庭院守卫、大肥鱼及角色挑战关卡；竞技场 PvP 不应用敌人难度倍率。
- 喝药时可以按正常移动速度移动、转向及锁定横移；期间不疾跑，也不能同时攻击、翻滚或格挡。腿部继续行走，手部保留喝药动作。
- 喝药仍为 1.25 秒，在进度超过 63% 时恢复生命和气力并消耗一瓶；生效前受击打断不消耗药瓶。
- 验证记录：`Docs/DIFFICULTY_HEALING_VALIDATION.md`。

绯刃天台启用独立的剑庭战斗规则，气力恢复、格挡消耗与药瓶收益与通用规则有所不同；其中喝药恢复最大生命的 35%，不直接补满气力。下文的通用气力数值不适用于该关卡。

暂停菜单中点击「设置」可调整主音量、画面动效、垂直同步、帧率上限与奔跑模式。奔跑默认为「切换」（按一次开启，再按一次关闭），也可改为「长按」（按住奔跑，松开停止）；键盘、手柄和触屏共用该偏好，选择会自动保存。主菜单「设置」也可修改奔跑模式。设置中按 Esc / Start 先返回暂停菜单，再按一次恢复游戏。

开始菜单和暂停菜单共用同一套设置面板。「按键设置」支持修改移动、奔跑、攻击、格挡、闪避、喝药、锁定、交互和暂停的键鼠键位，以及对应的手柄按钮。点击键位后输入新按键，Esc 取消；重复占用会提示冲突。「恢复默认键位」只重置按键绑定。改键自动保存，跨场景保留，暂停页、交互提示和技能栏会显示当前键位。手柄的双摇杆移动与视角保持默认。

显示设置在主菜单和暂停菜单共用并自动保存。帧率上限按 **30 → 60 → 120 → 144 → 不限** 循环；桌面端开启垂直同步时优先跟随显示器刷新率，关闭后恢复所选上限。关闭垂直同步时，单人菜单和后台窗口仍分别使用 30 / 15 FPS 节能限制；联机不使用这两项自动降帧，但会遵守手动选择的帧率上限，房主帧率也会影响当前网络更新节奏。移动端垂直同步由系统控制。详见 [Boss AI 与显示设置](Docs/BOSS_AI_AND_DISPLAY_SETTINGS.md)。

手机运行时采用横屏，自动显示安全区内的移动摇杆、拖动视角区域，以及轻击、重击、格挡、闪避、锁定、药瓶、奔跑、交互和暂停按键。格挡需要按住。电脑端不创建这些触控按钮。

## 连招与战斗

- **八段轻击**：斜挑 → 横刀半月 → 突刺转身 → 空跃（无伤害）→ 三次空中远程斩 → 斜冲落地，释放暗蓝沙石。
- **一轻 → 重**：反向斜劈；**二轻 → 重**：樱花突刺；**三轻 → 重**：后撤并依次发射三道月刃。
- **空跃 / 空中远程斩 → 重**：插剑下落；落地后接轻击可继续樱花突刺。
- **追加衔接**：樱花突刺、回身横扫、进步上挑、月刃追刺可以接回地面或空中连段；完整输入路线见 [连招与强化分支](Docs/CombatBranches.md)。
- **闪避衍生**：保留闪避轻击追刺、闪避重击跳劈与回风斩。完美闪避后可接轻击闪身横斩，或重击后跃落劈并释放火龙。
- **完美格挡强化**：保留一次持续 5 秒的强化选择。轻击接三连刺；重击接翻滚火龙，按住可蓄力；闪避获得双倍距离，并可继续轻击背闪突刺或重击回旋刀。大肥鱼扫尾 / 冲撞的专属反制仍可衔接反斩；冲撞需要起手弹反窗口。
- 月刃和空中远程斩使用近黑色弯月主体、猩红发光刃缘与沿飞行路径渐隐的拖尾；远程招式有实际飞行、扫掠碰撞和墙体遮挡。
- 命中、重击、斩杀、格挡和弹反分别使用不同强度的短顿帧、镜头冲击、火花和声音；手柄操作时加入短震动。普通敌人受击后退，死亡沿受击方向快速倒地。
- 技能栏根据最近使用的键鼠或手柄自动切换按键名。锁定翻滚沿镜头地面方向移动，模型滚转轴与位移一致；镜头贴近时暂时隐藏本地模型，避免看进模型内部。
- 基础输入缓存为 0.36 秒，攻击按输入顺序保留最多两次后续输入；连段恢复后另有 0.55 秒衔接窗口。剑招在起手约 45–75 毫秒后可接格挡或闪避，闪避约 0.1 秒后可转格挡；取消、受击、喝药会清除待执行攻击。
- 初始生命 **200**、气力 **630**、药瓶 **3**。轻击消耗 12、重击 22、处决 32、闪避 16 气力，疾跑每秒消耗 5。「定心」额外增加 15 点最大气力；「轻身」将闪避消耗降至 12。
- 通常停止消耗 0.18 秒后开始自然回复。移动时每秒回复 120 点，站定时每秒回复 165 点，轻重攻击中每秒回复 18 点。持续格挡时暂停自然回复。疾跑会将回气延迟设为 0.32 秒。命中回复 10 点，击杀回复 45 点，完美闪避每次动作最多回复 40 点，常规弹反消耗 8 点后回复 30 点。
- 基础刀剑伤害从 28 提高到 34，轻击 / 重击架势伤害为 26 / 56；走路和疾跑速度为 5 / 8，普通受击硬直缩短至 0.32 秒。
- **正面格挡**覆盖前方 180°，起手前 0.20 秒是完美格挡窗口。普通格挡承受擦伤，小怪攻击保留 40% 伤害，黄招保留 15%。Boss 红、蓝招可从正面挡住，普通格挡清空剩余耐力，完美格挡扣除最大耐力的 50%，最低扣至 0。完整结算见 [玩法与格挡规则](Docs/PLAY.md#战斗规则)。
- 喝药时左手会拿起药瓶，在动作约 63% 时消耗一瓶，恢复生命并补满气力；满血缺气力时也能喝药，生效前受击打断不扣药。
- 奶蛙使用项目中的 NaiWa 模型，待机双手自然下垂，近身抬手戒备，攻击由左右手蓄力、挥击、收回组成。死亡停止步行，倒地停留后在约 2.2–4.4 秒间逐渐消散；重生恢复模型。Boss 使用 DeepSeek 模型，拥有摆尾、冲撞、跃起压顶、泡泡阵和二阶段涡流等招式。

## 法术

击杀、拼刀、完美格挡与完美闪避可积攒法术能量，上限 300。技能栏显示当前能量、消耗与按键，法术按键也可在设置中修改。

- **黑棺**：消耗满槽能量，吟唱结束后封印当前地图中符合条件的敌人，处决普通敌人并对 Boss 造成伤害。
- **镜花水月**：消耗半槽能量，对施放时前方视野内、无遮挡且符合条件的敌人触发镜碎效果，并提供短暂反击窗口与后续剑招。

## 合作联机

1. 在主菜单进入「多人联机」，填写昵称。房主创建房间，选择连接方式、公开 / 私人、房间名和人数上限。
2. **房间码**：使用 Unity Relay 创建房间，将生成的邀请码分享给同伴；同伴在加入入口输入房间码。该方式需要联网访问 Unity 服务。
3. **IP 直连**：房主设置 TCP 监听端口，同伴输入 `IP:端口`；跨网时使用端口映射或 TCP 穿透服务提供的域名 / IP 和外部端口。支持 `IPv4:端口`、`域名:端口` 和 `[IPv6]:端口`。
4. **公共房间**：可刷新房间列表，查看关卡、难度和人数后直接加入。公开 IP 房间还需填写同伴可访问的公网地址与端口；房间列表登记不会代替端口映射。
5. 房主选择关卡、难度后点击「共同启程」。庭院保留清理守卫的完整流程；竞技场至少两人，可互伤、格挡、弹反、锁定对手，击杀计分，阵亡 3 秒后重生并有 2 秒保护，主动攻击解除保护。
6. 大肥鱼基础最大血量为 `1400 × 当前房间人数`，再叠加难度等倍率；角色 Boss 使用各自基础生命值。加入 / 退出时保留剩余血量比例，战斗节奏也会随人数调整。左上角显示本人昵称，其他玩家头顶显示昵称与血条。

IP 直连默认端口为 7777，端口映射使用 TCP。房间码使用 Relay 的 UDP / DTLS 传输；当前 Relay 实现需要支持 UDP 的客户端，不支持 WebGL。两种方式均由房主负责战斗与世界状态，客户端提交操作。公共房间目录使用 Unity Lobby；Relay 与目录功能需要有效的 Unity Services 项目配置及服务连接。

庭院合作中，仍有队友存活时，倒下的玩家 5 秒后重生；全部玩家倒下则整队失败，停止自动重生。任一玩家可在失败界面点击「重来」，全队重新开始。竞技场继续采用 3 秒重生与击杀计分。
联机各端需要使用同一游戏版本。

大肥鱼使用替换后的 `Assets/Art/Models/DeepSeek/DeepSeek.fbx`，保留原 GUID 和材质映射。生命低于 55% 时进入二阶段并开启模型的 `TiePen` 铁盆形态键；低于 25% 时进入狂潮。新增二连摆尾、折返冲撞、延迟重砸与双轮全队点名。扫尾只在可见水刃扫过时命中，前扫和回身扫各有安全扇区；地面预警、范围与联机显示使用同一组角度。庭院与战斗有不同的原创合成音乐，并随战斗状态淡入淡出。

Boss 会按距离选择可触及的招式、追击远处目标，并减少连续重复；独立弹幕或双生伙伴的行动不再阻塞自身恢复计时。行为观察会影响选招与后续分支，喝药或蓄力等反应基于已发生的动作并保留观察延迟；中途变招重新播放完整预警，弹反可阻止追加追击。详见 [Boss 攻防博弈改造](Docs/BossDuelRedesign.md)、[遭遇战手感](Docs/ENCOUNTER_FEEL_VALIDATION.md) 和 [Boss AI 与显示设置](Docs/BOSS_AI_AND_DISPLAY_SETTINGS.md)。

## 项目结构

- `Assets/Scripts/Trial/`：按角色（`Actors`）、动作（`Animation`）、关卡与相机（`World`）、界面（`UI`）、输入（`Input`）、联机（`Networking`）、表现（`Effects`）、试炼进程（`Runs`）和核心逻辑（`Core`）分组。
- `Assets/Scripts/Menu/`：水墨开始界面、房间配置与按钮动效。
- `Assets/Art/Models/`：Tomorin、DeepSeek、NaiWa 模型。
- `Assets/Anims/Trial/`：19 个可预览的角色骨骼动作片段；运行时由同一套程序姿态驱动。
- `Assets/Editor/Trial/`：场景装配和资源配置（`Builders`）、维护工具（`Tools`）及 Play Mode 验证（`Validation`）。
- `Docs/`：更详细的玩法、图标及验证记录。

`Tools > Tomorin > Apply combat and interface polish` 可更新奶蛙场景引用、动画预览资产及开始菜单按钮。`Verify combat and interface polish (Play Mode)` 验证主要交互，报告写入 `Logs/Trial/Validation.txt`。这些操作不导出游戏安装包。

这是持续迭代中的原型。手机真机触感、不同屏幕与公网多机联机仍需要在目标设备及网络环境中验证。
