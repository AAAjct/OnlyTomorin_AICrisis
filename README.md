# 只鹅 · 智械危机

一个水墨庭院中的第三人称剑术动作游戏原型。扮演凑企鹅 Tomorin，击败三名奶蛙拳卫，解除庭门封印，迎战「大肥鱼 · DeepSeek」。支持单人、Mirror TCP 多人合作，以及竞技场自由决斗；房间不设置玩法人数上限。

## 运行项目

- Unity **6000.3.27f2**，URP **17.3.0**，Input System **1.20.1**。
- 打开 `Assets/Scenes/InkStart.unity`，点击 Play，从「单人游玩」或「局域网联机」开始。单人关卡列表只有「庭院 (Boss · 大肥鱼)」；联机下拉入口打开同款列表，依次显示「竞技场」「庭院 (Boss · 大肥鱼)」。
- 庭院始终从入口开始，先打三名守卫。入场时每名玩家从三个随机增益中选一个，Boss 同时获得一项小幅随机增益；竞技场不启用增益。
- `Assets/Scenes/AshenCourt.unity` 是战斗场景；直接运行该场景时会显示试炼菜单。
- 左侧香炉可恢复生命、气力和药瓶，并设置本局重生点；休息会重置敌人。
- 正常流程必须击败三名奶蛙，左右围栏防止绕开封印。进入庭心后，圆形斗场入口封闭，击败 Boss 或重新开始后解除。

## 操作

| 操作 | 键鼠 | 手柄 |
| --- | --- | --- |
| 移动 / 镜头 | WASD / 鼠标 | 左 / 右摇杆 |
| 奔跑（切换 / 长按） | Shift | 左摇杆按键 |
| 轻击 | 鼠标左键 / J | X / 西侧按钮 |
| 重击 | Q | RB / R1 |
| 格挡 / 弹反 | 按住鼠标右键 / K | LB / L1 |
| 闪避 | Space | B / 东侧按钮 |
| 锁定 | Tab / 鼠标中键 | 按下右摇杆 |
| 喝药 | R | 方向键上 |
| 香炉交互 | E | A / 南侧按钮 |
| 暂停 | Esc | Start |
| 菜单选择 / 确认 | 方向键 / Enter，或鼠标 | 方向键 / 左摇杆，A 确认 |

暂停菜单中点击「设置」可调整主音量、画面动效与奔跑模式。奔跑默认为「切换」（按一次开启，再按一次关闭），也可改为「长按」（按住奔跑，松开停止）；键盘、手柄和触屏共用该偏好，选择会自动保存。主菜单「设置」也可修改奔跑模式。设置中按 Esc / Start 先返回暂停菜单，再按一次恢复游戏。

开始菜单和暂停菜单共用同一套设置面板。「按键设置」支持修改移动、奔跑、攻击、格挡、闪避、喝药、锁定、交互和暂停的键鼠键位，以及对应的手柄按钮。点击键位后输入新按键，Esc 取消；重复占用会提示冲突。「恢复默认键位」只重置按键绑定。改键自动保存，跨场景保留，暂停页、交互提示和技能栏会显示当前键位。手柄的双摇杆移动与视角保持默认。

手机运行时采用横屏，自动显示安全区内的移动摇杆、拖动视角区域，以及轻击、重击、格挡、闪避、锁定、药瓶、奔跑、交互和暂停按键。格挡需要按住。电脑端不创建这些触控按钮。

## 连招与战斗

- **四段轻击**：正手斜斩 → 反手横斩 → 低位升斩 → 过顶终结斩。
- **一段轻击 + 重击**：升斩。
- **两段轻击 + 重击**：突刺，攻击距离更长、正面判定更窄。
- **三段轻击 + 重击**：终结重斩。
- **两段或三段轻击 + 闪避**：回风斩，在闪避中发动环身攻击。
- **闪避 + 轻击**：追击突刺。
- **极限闪避后的下一次轻击**：3 秒内可发动带虚影与爆裂斩光的闪身横斩，伤害为基础普攻的 1.5 倍；冲刺受场景碰撞约束。
- **完美弹反大肥鱼的扫尾 / 冲撞**：取消来招，衔接反斩与短慢放；反斩有 3 秒内置冷却。冲撞只能用起手弹反窗口化解，持续格挡仍会被击中。
- 命中、重击、斩杀、格挡和弹反分别使用不同强度的短顿帧、镜头冲击、火花和声音；手柄操作时加入短震动。普通敌人受击后退，死亡沿受击方向快速倒地。
- 技能栏根据最近使用的键鼠或手柄自动切换按键名。锁定翻滚沿镜头地面方向移动，模型滚转轴与位移一致；镜头贴近时暂时隐藏本地模型，避免看进模型内部。
- 输入缓存为 0.36 秒。轻击命中后可衔接闪避，收招阶段可接格挡；轻击后段可接下一段轻击或重击。攻击起手和命中阶段仍需要承担出招风险。
- 初始生命 160、气力 180、药瓶 3。轻击消耗 19、重击 35、闪避 25 气力；疾跑每秒消耗 8 气力。「定心」增益额外增加 15 点，最大气力为 195。
- 格挡起手 0.20 秒内可弹反；持续格挡消耗气力并承受少量伤害。红色危招应通过闪避或走位应对。
- 喝药时左手会拿起药瓶，在动作约 63% 时消耗一瓶并恢复生命；生效前受击打断不扣药。
- 奶蛙使用项目中的 NaiWa 模型，待机双手自然下垂，近身抬手戒备，攻击由左右手蓄力、挥击、收回组成。死亡停止步行，倒地停留后在约 2.2–4.4 秒间逐渐消散；重生恢复模型。Boss 使用 DeepSeek 模型，拥有摆尾、冲撞、跃起压顶、泡泡阵和二阶段涡流等招式。

## 合作联机

1. 房主在「局域网联机」填写名字及 TCP 端口，创建房间。
2. 同伴填写房主局域网 IP；跨网时填写 TCP 穿透服务提供的域名或 IP 和外部端口。
3. 可以直接把 `frp-six.com:24456` 粘贴到地址框，界面会自动填为地址 `frp-six.com`、端口 `24456`。
4. 支持 `[IPv6]:端口` 的输入拆分；不拆分无方括号的纯 IPv6 地址。
5. 房主通过关卡下拉入口选择庭院或竞技场，再点击「共同启程」。庭院保留清理守卫的完整流程；竞技场至少两人，可互伤、格挡、弹反、锁定对手，击杀计分，阵亡 3 秒后重生并有 2 秒保护，主动攻击解除保护。
6. Boss 最大血量为 `1400 × 当前房间人数`，加入 / 退出时保留剩余血量比例；韧性、弹幕与节奏也随人数调整，伤害增幅设有上限。左上角显示本人昵称，其他玩家头顶显示昵称与血条。

默认端口为 7777。端口映射使用 TCP；服务器负责战斗与世界状态，客户端提交操作。

大肥鱼使用替换后的 `Assets/Art/Models/DeepSeek/DeepSeek.fbx`，保留原 GUID 和材质映射。生命低于 55% 时进入二阶段并开启模型的 `TiePen` 铁盆形态键；低于 25% 时进入狂潮。新增二连摆尾、折返冲撞、延迟重砸与双轮全队点名。扫尾只在可见水刃扫过时命中，前扫和回身扫各有安全扇区；地面预警、范围与联机显示使用同一组角度。庭院与战斗有不同的原创合成音乐，并随战斗状态淡入淡出。

本轮检查说明见 [Docs/ENCOUNTER_FEEL_VALIDATION.md](Docs/ENCOUNTER_FEEL_VALIDATION.md)。

## 项目结构

- `Assets/Scripts/Trial/`：战斗、动作、相机、庭院、HUD、触控和联机。
- `Assets/Scripts/Menu/`：水墨开始界面、房间配置与按钮动效。
- `Assets/Art/Models/`：Tomorin、DeepSeek、NaiWa 模型。
- `Assets/Anims/Trial/`：19 个可预览的角色骨骼动作片段；运行时由同一套程序姿态驱动。
- `Assets/Editor/Trial/`：场景装配、动画烘焙、Play Mode 验证工具。
- `Docs/`：更详细的玩法、图标及验证记录。

`Tools > Tomorin > Apply combat and interface polish` 可更新奶蛙场景引用、动画预览资产及开始菜单按钮。`Verify combat and interface polish (Play Mode)` 验证主要交互，报告写入 `Logs/Trial/Validation.txt`。这些操作不导出游戏安装包。

这是持续迭代中的原型。手机真机触感、不同屏幕与公网多机联机仍需要在目标设备及网络环境中验证。
